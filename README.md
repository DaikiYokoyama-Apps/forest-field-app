# 毎木確認 (現地用)

森林の毎木調査を、スマホで自分の位置を見ながら行うための Web アプリ。

- 地形図 (陰影・等高線) の上に、点群解析で見つけた木を胸高断面積に比例した円で描く
- 木ごとに、存在の確認・実測値・樹種・階層・状態・被害・備考を記録する
- GPS で現在地と軌跡を表示する。重ねたいポリゴン (GeoJSON・KML) も読める
- 記録は CSV・JSON、軌跡は GPX で書き出す

調査データ (`.forest.json`) は解析アプリ (forestscan) が書き出し、スマホで読み込む。
データと記録はスマホの中 (ブラウザの保存領域) だけに置き、どこにも送信しない。
このリポジトリにはアプリのプログラムだけがあり、調査データは含まない。
